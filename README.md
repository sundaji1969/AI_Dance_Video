# AI Dance Video Project

A Python-based project to create a seven-member dance video
using personal photographs, AI video generation and background music.

## Features
- Seven-member group photo composition
- Copacabana beach background
- AI video generation using Kling
- Background music integration
- Final MP4 video assembly

## Project Structure

- Input: Source photographs and music
- Output: Final video and image files
- python_code: Python scripts
- generated_clips: AI-generated video clips

## Requirements

- Python 3.10+
- Pillow
- MoviePy
- rembg
- requests
- python-dotenv

## Setup

Install dependencies:

pip install pillow moviepy rembg requests python-dotenv

## API Configuration

Create a .env file in the project root:

KLING_API_KEY=your_api_key_here

Never upload your API key to GitHub.

## Run

Activate your virtual environment and run the required Python scripts.
